# Unify 3 SDK for iOS

This package is for integrating with Unify 3 from Swift applications on iOS.

## Documentation

Getting started guides are published at:

<https://kaelusrf.github.io/Unify3Sdk-Docs>

API reference docs are published at:

<https://kaelusrf.github.io/Unify3Sdk-Apple/documentation/unify3sdk>

## Examples

The `Unify3SdkExample` SwiftUI iOS app can be found in the repository's Examples directory:

<https://github.com/KaelusRF/Unify3Sdk-Apple/tree/main/Examples>

## Installation

Add the package dependency in Xcode using the package repository URL, then link the `Unify3Sdk` product in your app target.
